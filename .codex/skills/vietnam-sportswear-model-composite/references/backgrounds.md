# Bundled Backgrounds

All paths are relative to this skill folder.

| File | Best Use | Notes |
|---|---|---|
| `assets/backgrounds/telephoto-narrow-model-zone-square.png` | Default approved background for model-first shop composites. | Square `1:1`, same X24Sport shop identity, telephoto feel, clear floor/model zone, no visible low-shelf zip-bag wall. |

Selection guidance:

- Use only square `1:1` backgrounds from this table.
- Prefer the approved telephoto background when realism matters more than showing the whole shop.
- Keep the product arrangement consistent with the selected reference plate across a set of images.
- When compositing a full-body model, keep the model in existing open floor zones and do not add merchandise on the floor.
- Reject or regenerate any background that shows zip-bagged products, plastic-wrapped apparel, or flat packaged clothes stacked below cabinet height, on the floor, or along lower shelves.
