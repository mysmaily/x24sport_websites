# Bundled Backgrounds

All paths are relative to this skill folder.

| File | Best Use | Notes |
|---|---|---|
| `assets/backgrounds/reception-reverse-wide.png` | Approved reverse angle from inside/near reception counter shooting toward the entrance. | Good when the user wants the original liked layout and more store context. |
| `assets/backgrounds/entrance-inward-fuller-irregular.png` | Fuller shop background from near the entrance looking inward. | Includes fuller shelves and more natural lower folded goods; no caps. |
| `assets/backgrounds/telephoto-narrow-model-zone.png` | Portrait or model-first photos where the shop should be supporting context. | Best default for low-AI-tell model composites. Narrower, telephoto feel, clear model zone. |
| `assets/backgrounds/telephoto-casual-left-racks.png` | Busier lived-in shop feel with racks and goods visible. | Good for natural retail density, still leaves model room. |
| `assets/backgrounds/telephoto-horizontal-entrance-soft.png` | Horizontal model photo with mild background softness and entrance depth. | Good for banners, web hero crops, and model-first composition. |

Selection guidance:

- Prefer telephoto backgrounds when realism matters more than showing the whole shop.
- Prefer `reception-reverse-wide.png` when the user asks for the counter-to-door composition.
- Prefer `entrance-inward-fuller-irregular.png` when the user asks to show a fuller shop.
- When compositing a full-body model, keep the model in existing open floor zones and do not add merchandise on the floor.
