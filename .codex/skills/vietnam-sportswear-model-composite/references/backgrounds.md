# Bundled Backgrounds

All paths are relative to this skill folder.

| File | Best Use | Notes |
|---|---|---|
| `assets/backgrounds/telephoto-narrow-model-zone-square.png` | Default square catalog background. | Square `1:1`, model-first, approved shop identity, clear model zone. |
| `assets/backgrounds/reception-reverse-wide.png` | Approved reverse angle from inside/near reception counter shooting toward the entrance. | Good when the user wants the original liked counter-to-door layout and more store context. |
| `assets/backgrounds/entrance-inward-fuller-irregular.png` | Fuller shop background from near the entrance looking inward. | Includes fuller shelves and more natural lower folded goods; no caps. |
| `assets/backgrounds/telephoto-narrow-model-zone.png` | Portrait or model-first photos where the shop should be supporting context. | Narrower telephoto feel, clear model zone, good default when realism matters more than showing the whole shop. |
| `assets/backgrounds/telephoto-casual-left-racks.png` | Busier lived-in shop feel with racks and goods visible. | Good for natural retail density, still leaves model room. |
| `assets/backgrounds/telephoto-horizontal-entrance-soft.png` | Horizontal model photo with mild background softness and entrance depth. | Good for banners, web hero crops, and model-first composition. |
| `assets/backgrounds/entrance-inward-fuller-caps-original.png` | Historical/reference version of the near-entrance shop angle. | Contains caps; use only if the user explicitly asks for the older cap version. Prefer `entrance-inward-fuller-irregular.png` otherwise. |

Selection guidance:

- Prefer `telephoto-narrow-model-zone-square.png` for ordinary square ecommerce images.
- Prefer telephoto backgrounds when realism matters more than showing the whole shop.
- Prefer `reception-reverse-wide.png` when the user asks for the counter-to-door composition.
- Prefer `entrance-inward-fuller-irregular.png` when the user asks to show a fuller shop.
- Prefer `telephoto-horizontal-entrance-soft.png` for horizontal banners and storefront crops.
- Use `entrance-inward-fuller-caps-original.png` only on explicit request because caps were previously removed from the preferred version.
- When compositing a full-body model, keep the model in existing open floor zones and do not add merchandise on the floor.
- If a background has distracting low-shelf zip-bag stacks, reduce their prominence with depth of field, crop, or regenerate a cleaner background instead of emphasizing them.
