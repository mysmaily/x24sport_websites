# Designer Checklist

This reference adapts the installed `owl-listener/designer-skills` repo for outdoor apparel image design. The source is installed locally at:

`/Users/hoang/.codex/designer-skills/owl-listener-designer-skills`

Use this checklist before generation for art direction and after overlay for critique.

## Layout And Hierarchy

- Make the garment the entry point, then faces/activity, then feature overlay, then logo/hotline.
- Use the law of proximity: group feature title/detail/icon into one readable unit.
- Use common region sparingly: one coherent translucent rail/grid/row is better than scattered badges.
- Use continuity: align feature blocks to a strong vertical or horizontal edge.
- Keep the overlay away from the center torso when that torso carries the most important design.

## Typography

- Use short Vietnamese feature titles, normally 2-4 words.
- Keep details supportive and shorter than one line when possible.
- Use strong title/detail contrast, but no oversized text that competes with the shirt.
- Reject outlines, fake stickers, warped generated text, or text printed onto the garment.

## Color

- Derive overlay accents from the shirt palette or Mayaodongphuc orange.
- Keep contrast high enough for thumbnail reading.
- Avoid a heavy opaque panel unless the photo is too busy for lighter treatment.
- Do not let accent colors imply a different product colorway.

## Spacing And Density

- Use generous inner padding and consistent gaps.
- Keep 3-4 features maximum for v1 images.
- Prefer one edge-aligned cluster over multiple floating cards.
- On square images, leave breathing room around the logo and feature cluster.

## Critique Pass

Ask these seven questions:

1. Hierarchy: does the shirt design read first?
2. Brand consistency: is the real Mayaodongphuc logo used once and unchanged?
3. Composition: do people, shirt, and overlay balance naturally?
4. Typography: are feature labels readable and professionally spaced?
5. Color: does overlay color support the garment instead of fighting it?
6. Affordance: does the info overlay read as product annotation, not a clickable UI?
7. Density: is the image still a lifestyle/product image rather than a poster?
