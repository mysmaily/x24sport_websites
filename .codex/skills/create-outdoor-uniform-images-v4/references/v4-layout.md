# V4 layout reference

## Canvas

Default: landscape 3:2, 1536×1024 or larger equivalent.

Use these as flexible proportions, not pixel-perfect constraints:

- outer safe margin: 2.0–3.0% of canvas width;
- left information zone: x=0–28%W, y=0–88%H;
- hero: x≈24–100%W, y=0–58%H, allowed to extend under the left fade;
- support A: x≈25–60%W, y≈54–88%H;
- support B: x≈60–100%W, y≈54–88%H;
- footer: x=2–98%W, y≈88–98%H with rounded outer corners.

The hero and support windows should visually touch/overlap enough to feel like one board, but borders must remain clean.

## Left information zone

The desired V4 look is not a heavy white sidebar. Start from near-white, add a 5–14% tint of the garment accent, and optionally a very soft accent gradient/transparent wash. Fade the right edge into the hero image. The panel can be slightly translucent where it overlaps the scene.

Order from top to bottom:

1. Mayaodongphuc logo;
2. optional tiny product/category icons if already bundled/available;
3. campaign slogan;
4. subtle decorative sport motif;
5. four feature callouts.

Keep generous negative space. The product-color accent should appear in headings, icons, motif and footer.

## Source Images

V4 defaults to exactly two accepted scene images plus one catalog board. Use `Image 1` as the catalog hero source. Use `Image 2` as the main supporting context source. The second support window may use a distinct crop from `Image 1` or `Image 2`; do not generate a third scene image unless the user explicitly asks.

## Hero

Use 3–5 people, with 4 as the default. Keep faces and shirts large enough to read. A back-facing person may be placed at far right when the back artwork is important. Background should be believable and secondary.

## Supporting windows

Use two rounded landscape windows with thin light borders. Prefer one social/team interaction and one walking/activity scene. Keep the same garment lock. With the default two-image limit, crop the available scenes so the windows differ in subject, scale, or action; avoid using the same exact crop twice.

## Footer

Deep garment-accent background, not automatically red. Divide into five zones: four compact features + contact. Use thin separators. White icons/text are preferred when contrast allows. Contact zone gets the largest footer text but remains subordinate to the hero/slogan.

## Dynamic product-color examples

- burgundy/red garment → wine/burgundy footer and headings;
- navy/royal garment → navy/blue footer and headings;
- green garment → deep forest/emerald footer and headings;
- black/gray garment → charcoal footer with a secondary garment accent;
- bright yellow/orange garment → use a deeper related shade for footer; do not use fluorescent large surfaces.

Never sacrifice text contrast to color matching.
