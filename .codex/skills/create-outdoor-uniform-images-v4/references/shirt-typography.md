# Shirt typography and slogan art direction

Use this stage only when the supplied garment does not already contain approved chest artwork, or when the user explicitly asks to add/replace shirt text. Existing customer/team artwork always wins unless replacement is requested.

## Slogan library

Prefer short copy that remains legible on moving fabric:

- ONE TEAM
- BETTER TOGETHER
- WE ARE ONE
- STRONGER TOGETHER
- EXPLORE TOGETHER
- OUTDOOR CREW
- GO EXPLORE
- ALL IN
- GOOD VIBES
- ONE TEAM • ONE DREAM
- TOGETHER WE WIN
- CAMP • EXPLORE • REPEAT
- CÙNG NHAU BỨT PHÁ
- KẾT NỐI • BỨT PHÁ

For a generic ecommerce sample, prefer ONE TEAM, EXPLORE TOGETHER, BETTER TOGETHER, OUTDOOR CREW, or ALL IN. Use event/company names only when supplied by the user.

## Typography lock

Before rendering, define the shirt graphic as a designer would. Record:

1. exact slogan and spelling;
2. hierarchy: primary word/line versus supporting line;
3. composition: stacked, compact horizontal, arched, badge-free athletic lockup, or restrained two-line editorial lockup;
4. type character: bold geometric sans, condensed athletic sans, or clean grotesk; never default office typography;
5. tracking, line spacing, alignment, and approximate print width relative to the chest;
6. one restrained supporting device when useful: short rule, tiny star/dot, small mountain/sun/route motif, or year/location supplied by the user;
7. ink colors chosen from the garment palette with strong contrast and normally no more than two print colors;
8. print method appearance only when known; otherwise describe a clean matte screen-print/transfer-like visual result without making a technical claim.

## Designer-quality rules

- The slogan must read as a composed garment graphic, not text typed onto a photo.
- Use hierarchy, spacing, optical centering, and intentional negative space.
- Default print width: about 24–32% of visible torso width for a compact mark, or 45–60% for a hero chest graphic. Adapt to the supplied design.
- Keep artwork clear of collar seams, armpits, side seams, and extreme wrinkle zones unless the reference intentionally uses them.
- Respect the shirt's panel geometry. Center against the visual torso, not blindly against the image canvas.
- Integrate the print into fabric perspective, curvature, wrinkles, occlusion, lighting, and texture. It must not float above the cloth.
- Do not add rectangular text boxes, fake embroidered patches, generic badges, clip-art emblems, bevels, glow, drop shadows, metallic effects, or decorative clutter unless explicitly requested.
- Do not put the Mayaodongphuc corner brand logo on the shirt.
- Across a group, every copy of the same design must use identical spelling, layout, relative scale, and ink colors while naturally deforming with each body and pose.

## Text fidelity gate

Reject and correct any garment where the slogan has malformed letters, wrong spelling, duplicated characters, inconsistent line breaks, changed wording, random extra text, or materially different typography between models. For a correction pass, preserve the accepted face, pose, lighting, garment colors, and composition and edit only the shirt graphic.

When exact text fidelity cannot be achieved reliably on many people, reduce the number of prominently front-facing slogan shirts, favor 3–4 models, or show the slogan clearly on the hero/foreground models while secondary shirts use a natural angle that does not require fully readable text. Never hide a known text error by blur.
