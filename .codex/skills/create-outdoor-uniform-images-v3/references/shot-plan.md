# Default website shot guidance

Use this guidance when the user asks for a set but does not define each shot. Default to two square 1:1 clean gallery images plus one square 1:1 catalog board for the website workflow, but follow explicit output count/aspect-ratio requests. Combine this guidance with `layout-presets.md`.

| Slot | Role | Default ratio | Direction |
|---|---|---:|---|
| 1 | Clean gallery hero | 1:1 | Prefer 3–4 adults for the hero; use 5–7 only when the scene benefits in a park/picnic setting; use a head-to-mid-thigh or head-to-knee crop with clear shirt fronts; choose a naturally balanced loose arc, diagonal, staggered cluster, or layered formation. No feature/footer overlay by default. |
| 2 | Clean gallery detail/context | 1:1 | Use a different count, normally 3–5, with 6–7 reserved for wider lifestyle context in a closer picnic, walking, or clean comparison scene; vary formation and pose while keeping shirt fronts, collar, sleeve, and print visible. No feature/footer overlay by default. |
| 3 | Catalog board | 1:1 | Use `campaign-composite-3` or `front-back-showcase` when useful. Include one bundled corner logo plus the deterministic feature/hotline information system. If using a bottom band, reserve the bottom 10–12% as footer-safe space and keep all supporting frames above it. |

## Casting

- Default to Vietnamese/Southeast Asian adults aged approximately 20–35.
- Use a balanced mixed-gender cast unless the request specifies women, men, family, school, or another group.
- Make faces individually recognizable, commercially suitable, warm, and non-identical.
- Vary height, build, hairstyle, and pose subtly; keep styling commercially cohesive.
- Reuse a coherent casting direction, but do not promise exact identity continuity unless a face reference is supplied and supported.
- Bias group size toward 3–5 people for fidelity; use 6–7 selectively, formation, pose mix, camera distance, and gaze across the two images. Avoid repeating the same group count or a fixed triangular composition.

## Outdoor art direction

- Favor real daylight, soft sun, open shade, green lawn, picnic mat, resort garden, light team-building props, and uncluttered backgrounds.
- Keep exposure realistic. Avoid nuclear greens, clipped white shirts, orange skin, fantasy sunsets, excessive HDR, and oversaturated skies.
- Favor 35–70 mm photographic perspective. Use believable depth of field without cutting sharp halos around hair.
- Make body language friendly and spontaneous: walking, laughing, arranging picnic items, leaning naturally, or light team activity.
- Avoid rows of rigid catalog poses unless the user requests a lineup.
- Keep all square outputs shirt-first. Reduce lower-leg, shoe, and empty-lawn area; use full-body framing only when it still reads as a product image inside the 1:1 crop.
- Clean gallery images should remain usable as normal product gallery assets: no feature footer, no hotline, no heavy panels. Use only a small deterministic corner logo if the user asks for branded gallery images.
- Catalog-board images may carry the feature system. For bottom-band boards, compose the photo with a reserved footer-safe lane before overlay; do not place the lower subframes behind the band.
- Keep the group composition natural and visually balanced; do not push models to one side for graphics. Reserve a clean top-left or top-right corner for the fixed vertical logo, and use a quiet edge or side band for icon + text feature callouts on paint swashes or diagonal gradient accents. Choose the overlay layout dynamically: horizontal row, compact 2x2 grid, or slim vertical rail inspired by professional sportswear shop graphics. Rail layouts should use the image edge as the text alignment axis with only a small professional margin, and use large thumbnail-readable text; if a painterly patch looks awkward, use a clean evenly rounded translucent shape. Let the script scan candidate regions and choose dark or light text from the sampled region brightness. The overlay may cover noncritical plain sleeve or torso fabric on one or two secondary shirts when it improves legibility; never place it over a face, hair, hand, collar, approved artwork, customer/team mark, or the main visible design detail.

## Children variant

When children are explicitly requested, replace the adult cast completely or use the exact family/teacher mix requested. Use play, picnic, school outing, nature discovery, or supervised team activity. Keep shorts/skirts practical, poses active but safe, expressions natural, and camera framing neutral and age-appropriate.

## One or several garment designs

- One design: repeat it consistently across the group; size and natural wrinkles may vary.
- Coordinated colorways: assign them intentionally and balance colors across the composition.
- Front/back pair: place some people front-facing and a smaller number naturally turned to show the back.
- Different designs: label A/B/C in the prompt and state exactly which people wear each; never blend design features.
